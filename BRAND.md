# Zervyra — brand system

**Proizvod:** Zervyra Vault  
**Tagline:** Tvoje tajne. Tvoja kontrola.

Zervyra je zamišljena kao samostalan security brand, tako da isti identitet kasnije može pokriti Zervyra Vault, Zervyra Browser, Zervyra Sync i mobilne aplikacije.

## Vizualni smjer
- Obsidian: `#0A0D13`
- Surface: `#111721`
- Field: `#19212E`
- Iris: `#6958EE`
- Iris Light: `#8B7CFF`
- Secure Mint: `#32D7A0`
- Primary text: `#F7F9FD`
- Muted text: `#8794A8`

Logo koristi zaštitni štit i snažno geometrijsko slovo **Z**. Mint točka predstavlja provjereno/sigurno stanje, dok violet ostaje glavni prepoznatljivi accent.

Naziv je prije ove revizije provjeren kroz javnu web i GitHub pretragu. To nije zamjena za formalnu EUIPO/USPTO provjeru žiga prije komercijalne registracije.

## Reproducibilni assets

Kanonski vektorski logotipi su SVG. Windows ICO je pohranjen kao numerirani Base64 segmenti u `native/cmd/vault/assets/zervyra.ico.b64.part*`. Build ih deterministički spaja i dekodira prije izrade Setup EXE-a; isti segmenti se embedaju u aplikaciju za titlebar/taskbar ikonu.
