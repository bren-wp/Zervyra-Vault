# Zervyra Vault 1.0.1

**Tvoje tajne. Tvoja kontrola.**

Zervyra Vault je lokalni Windows password manager napravljen kao native Go aplikacija bez obaveznog računa, clouda ili Python runtimea.

## Prvo pokretanje

Portable i Setup izdanje namjerno startaju bez otključanog trezora. U 1.0.1 prvi ekran više ne prikazuje zbunjujuće “Trezor je zaključan” kada trezor još ne postoji.

- **Novi trezor** — prvo korištenje; master lozinka se potvrđuje dvaput.
- **Otvori trezor** — postojeća `.bvault` datoteka.
- Tek nakon stvarnog zaključavanja otvorenog trezora prikazuje se **“Trezor je sigurno zaključan”**.

Kompletna dokumentacija i source nalaze se u ovom repozitoriju.
